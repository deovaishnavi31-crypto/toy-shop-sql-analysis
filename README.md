# Toy Shop Sales Analysis | PostgreSQL & SQL

## Project Overview
A one-year toy shop sales analysis project using PostgreSQL. The project studies customers, orders, products, revenue and sales channels.

## Dataset
- 1,000 customers
- 40 products
- 10,000 orders
- 21,298 order-item records
- 2025 sales data

## Tools
- PostgreSQL
- pgAdmin
- SQL
- GitHub

## Analysis
- Total customers and orders
- New vs returning customers
- Completed vs cancelled orders
- Cancellation rate
- Customers by city
- Total and monthly revenue
- Revenue by category
- Top products by revenue and quantity
- Top customers by spending
- Online vs store sales
- Average order value

## SQL Skills Used
SELECT, WHERE, GROUP BY, ORDER BY, COUNT, SUM, AVG, ROUND, JOIN, DISTINCT and date functions.

## Project Structure
- `data/` — project data
- `sql/` — SQL analysis queries
- `screenshots/` — screenshots of the SQL work
- `README.md` — project description

## Resume Summary
Analyzed 10,000 orders and 21,298 order-item records from one year of toy shop sales data. Used SQL JOINs, filtering, grouping and calculations to study sales, customers, products and orders. Calculated total revenue, monthly sales, cancellation rate, average order value and category-wise revenue. Found top-selling products, highest-spending customers, top cities and best-performing sales channels.
